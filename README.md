# Arafat Chess Master

দাবা সহকারী অ্যাপ (Kotlin + Jetpack Compose)।

## বিল্ড
1. VS Code-এ এই ফোল্ডার খুলুন
2. GitHub-এ `arafat-chess-master` নামে repo বানান
3. `git init && git add . && git commit -m "first" && git branch -M main`
4. `git remote add origin <repo-url> && git push -u origin main`
5. GitHub → Actions → "Build APK" → শেষ হলে Artifacts থেকে `Arafat-Chess-Master-APK` ডাউনলোড করুন
